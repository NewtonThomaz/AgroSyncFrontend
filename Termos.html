2. Funcionamento Offline-First e Stack IoT

O AgroSync opera sob a filosofia offline-first, garantindo a gravação local de todos os dados de telemetria mesmo sem conectividade imediata com a internet. A integração de Internet das Coisas (IoT) envolve dispositivos baseados em microcontroladores ESP32 equipados com sensores de temperatura, umidade (DHT22) e condutividade elétrica (EC). Os dados são transmitidos localmente via HTTP POST para o nosso servidor ou armazenados temporariamente no cache do navegador (PWA), sendo sincronizados com o backend na nuvem assim que uma conexão de rede estável for restabelecida.

3. Controle de Acesso e Perfis

O acesso à plataforma é estritamente controlado e validado por nossa tabela interna de colaboradores. Os níveis de acesso definidos no sistema e aceitos por este termo de forma intransferível são:

  • Root: Acesso total às configurações de infraestrutura corporativa, alteração de permissões administrativas de segurança e auditoria global do sistema.
  • Adm (Administrador): Permissão operacional plena para gerenciar culturas, estufas, limites de sensores, propriedades físicas e gestão de outros colaboradores vinculados à propriedade.
  • View (Visualizador): Acesso somente-leitura voltado a operadores e agrônomos de campo para acompanhamento diário de dashboards e emissão de relatórios simples.

4. Coleta de Telemetria e Notificações Push

Toda telemetria coletada pelo sistema (como leituras de condutividade elétrica) exige o registro de dois marcadores temporais obrigatórios: a dataHora (momento real aferido pelos sensores na estufa física) e o sincronizadoEm (momento de entrada e persistência dos dados no banco de dados central). O AgroSync monitora rigorosamente se o valorEC ultrapassa os limites mínimo (ceMin) ou máximo (ceMax) configurados para a cultura monitorada, disparando notificações push emergenciais via Firebase Admin SDK aos dispositivos cadastrados sempre que os limites forem extrapolados.

Você é inteiramente responsável pela confidencialidade e segurança dos seus dados de acesso (UUID do Colaborador) e pela calibração e manutenção corretas do seu hardware local (placas ESP32, sensores DHT22 e de condutividade elétrica). O AgroSync oferece ferramentas de monitoramento preditivo e alertas de estufa, mas não assume qualquer responsabilidade direta por perdas ou danos a colheitas decorrentes de falhas mecânicas locais, imperícia de calibragem física ou vazamento de credenciais administrativas.
